# Internet-Project

This backend API is built with Node.js and Express and uses mock JSON data for persistence. There is no real database connection; all data is stored in JSON files and modified in memory.

## Installation

- Install dependencies:
  ```bash
  npm install
  ```

## Run

- Start the server:
  ```bash
  npm start
  ```
- Or run directly with Node:
  ```bash
  node server.js
  ```

## Server details

- Port: `3000`
- Base URL: `http://localhost:3000`
- API base path: `/`

## Assumptions

- IDs are generated by taking the current maximum ID from the mock JSON array and adding 1.
- User role and identity are simulated via headers:
  - `x-user-role`: `user`, `manager`, or `admin`
  - `x-user-id`: numeric user ID for the current user
- Role-based access control is implemented in middleware.
- Validation is performed for required request body fields.
- All successful responses use JSON and error responses follow the standard error envelope.

## Running and testing

- Use the Postman collection at `docs/internet_all.postman_collection.json` to test the API.
- Make requests to `http://localhost:3000`.
- Use the `docs/API_REFERENCE.md` file for endpoint details.
